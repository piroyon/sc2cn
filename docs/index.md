# Sci2Common

ウェブページ上の生物の学名から、和名・英名・分類・写真を調べる Chrome 拡張機能です。
A Chrome extension that looks up English and Japanese common names, classification and photos for scientific names on web pages.

- [プライバシーポリシー / Privacy Policy](privacy-policy.html)
- [ソースコード / Source code](https://github.com/piroyon/sc2cn)
- [ご質問・不具合の報告 / Questions and bug reports](https://github.com/piroyon/sc2cn/issues)
